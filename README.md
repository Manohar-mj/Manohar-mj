**Project Overview**

Designed and implemented an end-to-end fintech data engineering solution using Databricks and Medallion Architecture.

**Key Implementations**

- Created structured and semi-structured datasets for customers, merchants, transactions, payments and refunds.
- Implemented Bronze, Silver and Gold data layers.
- Ingested CSV and JSON datasets into Bronze tables.
- Built data cleansing and transformation workflows using PySpark.
- Implemented Delta Lake tables across multiple processing layers.
- Developed customer, transaction, order and payment analytics tables.
- Implemented Databricks Jobs for pipeline orchestration.
- Configured task dependencies across Bronze → Silver → Gold.
- Developed a dedicated transaction processing workflow.
